Env

Env class abstract final

Acceso tipado a las variables de entorno compiladas vía --dart-define.

Cada valor se declara como const String.fromEnvironment('LITERAL') para que el AOT compiler de Dart lo embeba en el binario en release. Importante: el nombre DEBE ser un literal en la llamada — String.fromEnvironment(varName) con un parámetro variable devuelve cadena vacía en release (no se const-foldea).

Para desarrollo, pasar las variables en la línea de comandos:

flutter run \
  --dart-define=SUPABASE_URL=https://xxx.supabase.co \
  --dart-define=SUPABASE_ANON_KEY=eyJ...

O usar un fichero: --dart-define-from-file=dart_defines.json.
