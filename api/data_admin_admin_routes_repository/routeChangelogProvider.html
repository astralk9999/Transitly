routeChangelogProvider top-level property

FutureProviderFamily<List<RouteChangeRow>, String> routeChangelogProvider
final

Changelog de una ruta, CACHEADO por routeId. Antes la UI creaba el Future dentro de build() (FutureBuilder), así que cada rebuild del detalle generaba una petición nueva → volvía a "cargando" → parpadeo constante. Con este provider el resultado se memoiza y solo se vuelve a pedir si se invalida explícitamente.

Implementation

final routeChangelogProvider =
    FutureProvider.family<List<RouteChangeRow>, String>((ref, routeId) {
  return ref.watch(adminRoutesRepositoryProvider).listChangelog(routeId);
});
