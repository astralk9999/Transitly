IncidentRepositorySwr

IncidentRepositorySwr class

SWR para incidents — cache-first en lecturas; en create, escribe primero al remoto y, si responde, guarda en cache. Si el remoto no devolvió por red, el remoto ya encoló la mutación y devolvió la copia optimista; el SWR persiste esa copia en cache.
