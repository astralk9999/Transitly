NfcCardService

NfcCardService class

Service for reading Consorcio de Transportes de Andalucia transit cards via NFC Mifare Classic protocol.

Protocol reverse-engineered from the saldotarjetas Android app. Sector keys default to the values required by that card format; override at build time with --dart-define=NFC_KEY_SECTOR0=<hex> and --dart-define=NFC_KEY_SECTOR9=<hex> for environments where those defaults are inappropriate or legally sensitive.
