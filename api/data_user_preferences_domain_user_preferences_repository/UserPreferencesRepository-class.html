UserPreferencesRepository

UserPreferencesRepository class abstract

Preferencias del usuario autenticado. Singleton por uid — un solo registro por cuenta, creado automáticamente por el trigger on_auth_user_created en Supabase.

Usado por:

  • F4 (auth) — lee preferencias al hidratar la sesión.
  • F17 (apariencia) — persiste paleta y fondo personalizados.
  • F18 (accesibilidad) — persiste fontScale, colorBlindMode, etc.
